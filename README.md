### 🎮 About The Game

**JummyBlocks** is not just another Tetris clone. It's a minimal, juicy, and satisfying block-stacking experience built for flow state. With buttery animations, haptic feedback, and a lovely pastel-meets-neon UI, it's designed to be loved.

### 🔥 Features

- **🧊 Fluid Gameplay** - 60fps block movement with ghost preview & hard drop
- **🎨 Lovely UI/UX** - Glassmorphism, soft shadows, rounded corners, dark/light mode
- **✨ Juicy Effects** - Framer Motion animations, screen shake on clear, particle burst
- **🏆 Score System** - Combo streaks, T-Spin detection, Level progression
- **📱 Fully Responsive** - Play on desktop with keyboard or mobile with swipe controls
- **🔊 Sound On** - Satisfying pop & click sounds (toggleable)
- **💾 Auto-Save** - High score saved locally, resume game anytime

### 🕹️ Controls

| Action | Desktop | Mobile |
| :--- | :--- | :--- |
| Move | `←` `→` / `A` `D` | Swipe Left/Right |
| Rotate | `↑` / `W` / `Space` | Tap |
| Soft Drop | `↓` / `S` | Swipe Down |
| Hard Drop | `Space` / `Enter` | Double Tap |
| Hold | `C` / `Shift` | Hold Button |
| Pause | `P` / `Esc` | Pause Icon |

### 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript + React 19
- **Styling:** Tailwind CSS + shadcn/ui
- **Animation:** Framer Motion
- **State:** Zustand / React Hooks
- **Deployment:** Vercel
